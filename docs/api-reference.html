API Reference

Welcome to the Deriv Third-Party API documentation.

Authentication

All API requests require authentication using OAuth 2.0 or API tokens.

Authorization: Bearer YOUR_API_TOKEN

Base URL

The base URL for all API endpoints is:

https://api.deriv.com/v1

Getting User Info

Retrieve current user information:

GET /user/info

Response:

{
  "status": "success",
  "user_id": "12345",
  "username": "trader",
  "email": "user@example.com"
}

Get Markets

Fetch available markets and assets:

GET /markets

Webhooks

Subscribe to real-time events using webhooks. Send a POST request to:

POST /webhooks/subscribe
Content-Type: application/json

{
  "event_type": "trade_completed",
  "callback_url": "https://your-domain.com/webhook"
}

Error Handling

All errors are returned with appropriate HTTP status codes and error messages:

{
  "status": "error",
  "code": "INVALID_TOKEN",
  "message": "The provided API token is invalid"
}
